# Music Playlist App 🎵

แอปพลิเคชั่นสำหรับฟังเพลง ดูรายชื่อเพลงในอัลบั้ม และควบคุมการเล่นเพลงได้อย่างสะดวก

## ✨ ฟีเจอร์หลัก

- **ดูรายชื่ออัลบั้ม** - เลือกอัลบั้มที่ต้องการฟังจากรายชื่อ
- **เล่นเพลงอัตโนมัติ** - กดเล่นจะเริ่มเล่นเพลงแรกของอัลบั้มโดยอัตโนมัติ
- **ควบคุมการเล่น** - ปุ่มเล่น/หยุด ข้ามเพลง และดูตัวอักษรเพลง
- **เล่นเพลงแบบต่อเนื่อง** - เล่นเพลงตามลำดับในรายชื่อ
- **โชว์ความคืบหน้า** - แสดงเวลาที่เล่นและระยะเวลาทั้งหมด

## 📱 หน้าจอหลัก

### หน้า My Playlist
- แสดงรายชื่ออัลบั้มทั้งหมด
- แต่ละรายการมีรูปภาพ ชื่อ และศิลปิน
- ปุ่ม Play เพื่อเริ่มเล่นเพลง
- ปุ่ม Tap ไปเลือกเพลงอื่นจากอัลบั้ม

### Mini Player (ด้านล่าง)
- แสดงเพลงที่กำลังเล่น
- ปุ่มเล่น/หยุด และข้ามเพลง

### Music Screens
- แสดงรายชื่อเพลงทั้งหมดในอัลบั้ม
- แสดงไลริกเพลง
- ควบคุมการเล่นเพลง

## 🛠️ เทคโนโลยีที่ใช้

- **Flutter** - สำหรับสร้าง UI
- **Riverpod** - สำหรับจัดการสถานะ
- **Just Audio** - สำหรับเล่นเพลง
- **Cached Network Image** - สำหรับแสดงรูปภาพ
- **Jamendo API** - สำหรับดึงข้อมูลเพลง

## 🚀 วิธีใช้

1. **เปิดแอป** - จะแสดงรายชื่ออัลบั้ม
2. **กดปุ่ม Play** - เริ่มเล่นเพลงแรก
3. **ใช้ควบคุม** - เล่น หยุด ข้ามเพลง
4. **เลือกเพลง** - กด Tap ไปหน้า Music Screens เพื่อเลือกเพลงอื่น
